# 1121 線性代數 (Linear Algebra) 課程作業

## 📖 課程概述 / Course Overview

此倉庫包含了1121 線性代數課程的所有作業和報告程式碼。  
This repository contains all assignments and project code for the 1121 Linear Algebra course.

## 🛠️ 使用的程式語言 / Programming Languages Used

- **C#** - 用於測量系統和點燈遊戲 (Measurement system and Lights Out game)
- **C++** - 用於ILP問題生成和RREF計算 (ILP problem generation and RREF computation)
- **LINGO** - 用於整數線性規劃求解 (Integer Linear Programming solving)

## 📁 專案結構 / Project Structure

| 資料夾 / Directory | 描述 / Description |
|-------------------|-------------------|
| [**ILP**](./ILP/) | 整數線性規劃 - 圖形二分割問題 (Integer Linear Programming - Graph Bi-partition Problem) |
| [**Measurement**](./Measurement/) | C# 幾何測量系統 (C# Geometric Measurement System) |
| [**LightsOutGame**](./LightsOutGame/) | C# 點燈遊戲實作 (C# Lights Out Game Implementation) |
| [**RREF**](./RREF/) | 簡化階梯形矩陣計算器 (Reduced Row Echelon Form Calculator) |

## 🎯 學習目標 / Learning Objectives

通過這些專案，學習並應用：
- 矩陣運算和線性方程組求解
- 幾何計算和測量
- 整數線性規劃建模
- 程式設計實作線性代數概念

Through these projects, learn and apply:
- Matrix operations and linear equation solving
- Geometric calculations and measurements
- Integer linear programming modeling
- Programming implementation of linear algebra concepts
